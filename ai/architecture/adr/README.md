# ADR — Architecture Decision Records

Deep-form architecture decision records (fuller than a `decisions.md` entry
— used for decisions with lasting structural impact: framework choice,
data storage strategy, auth strategy, etc.). Cross-reference each ADR with
its corresponding `ARC-xxxx` entry in `ai/decisions/decisions.md`.

Naming: `ADR-<NNNN>-<kebab-title>.md`.
