# FS — Functional Specifications

Stores per-feature functional specifications (the concrete "FS-NNN" prompts
referenced in the roadmap, e.g. FS-001 Vehicle Master).
Naming: `FS-<NNN>-<kebab-title>.md`.

Every FS-001 onward must conform to
[`FSS-000-functional-specification-standard.md`](FSS-000-functional-specification-standard.md)
— the mandatory 21-section structure, Definition of Ready, Definition
of Done, Architecture Compliance Checklist, and Cross-FS Dependency
Rules (Constitution Rule 22). Copy `ai/templates/fs-template.md` as the
starting skeleton for any new FS. `FS-000` predates FSS-000 and is
exempt (different purpose — business DNA, not a module spec).
