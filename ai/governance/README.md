# Governance — Operational Standards

Operational engineering standards, distinct from the Constitution
(`ai/constitution/constitution.md`), which holds binding, rarely-changed
governance rules. Per AR-001 (Architecture Review AR-001), the
Constitution is now considered largely stable; new operational guidance
belongs here instead of as a new constitutional rule.

- `engineering-principles.md` — day-to-day engineering philosophy.
- `git-workflow.md` — commit/PR conventions.
- `branching-strategy.md` — branch naming and lifecycle.
- `release-policy.md` — versioning/release cadence (placeholder pending
  hosting decisions).

Code style itself (formatting, linting, per-language conventions) is
covered by `ai/architecture/standards/CSS-001-code-style-standards.md`,
not duplicated here.
