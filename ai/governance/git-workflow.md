# Git Workflow — BIKEVALUATOR

Operational standard, not a constitutional rule — update freely as the
team's actual practice is established.

## Commits

- One logical change per commit; message states the "why," not just the
  "what" (matches Constitution Rule 4's spirit for comments).
- Reference the driving prompt ID or decision ID in the commit message
  where applicable (e.g. `AEP-007`, `ARC-0003`).

## Pull Requests (once a remote/team workflow begins)

- PR description links the relevant FS/BR/decision IDs.
- No direct pushes to `main` once more than one contributor exists —
  deferred until that's actually true.

## Open Items

- Exact branch protection rules deferred until a remote repository and
  team size are established — this is a placeholder for that future
  decision, not a binding rule today.
